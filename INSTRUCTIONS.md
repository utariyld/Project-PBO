# Petunjuk Menjalankan Dashboard Data Strategis BPS

## 🚀 Cara Menjalankan Aplikasi

### 1. Install Dependencies
```bash
npm install
```

### 2. Jalankan Aplikasi
```bash
npm start
```

Aplikasi akan terbuka di http://localhost:3000

### 3. Login ke Sistem
Gunakan kredensial berikut untuk testing:

**Admin:**
- Username: `admin`
- Password: `admin123`

## 📋 Fitur yang Dapat Diuji

### ✅ Halaman Publik
1. **Beranda** - Lihat indikator strategis dan kartu interaktif
2. **Visualisasi Data** - Filter data dan lihat grafik interaktif
3. **Metadata** - Jelajahi metodologi dan definisi indikator
4. **Feedback** - Isi formulir saran dan feedback
5. **Tentang Kami** - Informasi lengkap tentang BPS

### 🔐 Halaman Admin (Setelah Login)
1. **Dashboard Admin** - Statistik sistem dan aktivitas
2. **Manajemen Indikator** - Kelola data indikator
3. **Manajemen Pengguna** - Administrasi pengguna
4. **Daftar Feedback** - Monitor feedback dari pengguna
5. **Pengaturan Sistem** - Konfigurasi sistem

## 🎨 Highlights Desain

- **Responsif**: Berfungsi optimal di desktop, tablet, dan mobile
- **Tema BPS**: Warna biru khas BPS dengan aksen emas
- **Interaktif**: Grafik yang dapat difilter dan diinteraksikan
- **Modern**: UI/UX yang bersih dan profesional
- **Accessible**: Mudah digunakan untuk semua kalangan

## 🛠️ Build untuk Production

```bash
npm run build
```

File production akan tersedia di folder `build/`
